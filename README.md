# Mansi Dangwal — Personal Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript.

## Features
- Responsive layout for desktop and mobile
- About, skills, projects, and contact sections
- Links to GitHub and LinkedIn
- Automatically updated footer year

## Technologies
- HTML5
- CSS3
- JavaScript

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.

## Before publishing
- Replace `your.email@example.com` with your email address.
- Replace the LinkedIn homepage URL with your own profile URL.
- Review the skills list and keep only technologies you can confidently discuss.
- Add more projects as you publish them.

## Deployment
This static website can be deployed using GitHub Pages.
